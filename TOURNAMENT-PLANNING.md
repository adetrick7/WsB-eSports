# Tournament / Big Announcement — Planning Notes

Working notes for the October 7 "big announcement" countdown on the site.
Nothing here is public-facing yet — this is just so ideas don't get lost
between conversations.

## The concept

- OG (Chapter 1) map, with Reload-style pacing/loot mixed in
- 100 players, duos (50 teams)
- Map code currently being used for reference/playtesting: 8875-9953-7938
  (NOTE: this is someone else's published island — no edit access to it.
  To have control over loot, a fresh island needs to be built from scratch
  in UEFN. Epic's rules specifically allow recreating Chapter 1 content,
  but it can't be monetized.)

## Loot customization (once building the real island)

- Item Spawner device — exact item/rarity/ammo per location
- Loot Pool — weighted random pools for chests/barrels
- Class Designer (UEFN) — custom weapon stat tweaks, for Reload-style balance
- Item Granter — triggered/event-based loot

## Hosting

- **DECISION: Going with WLS.gg (War Legend System) to actually host/run the tournament.**
  - https://www.wls.gg/ (found via https://system-beta.warlegend.net/)
  - Handles Epic sign-in, automated scoring, brackets — we don't build any
    of that ourselves.
  - WsB site's job is just to hype it and link people to sign up once the
    tournament is actually created on WLS.
  - Not set up yet — this is the plan for when we're ready to move forward.
