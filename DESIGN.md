# WsB Esports Design Direction

## Purpose

Make the site feel like a competitive Fortnite clan headquarters: confident, high-energy, readable, and community-first. It should feel custom to WsB, not like a generic gaming template.

## Visual personality

- Dark, cinematic, and energetic.
- Purple is the signature color; it is a highlight, not the entire canvas.
- Use sharp structure, large display type, subtle scan-line or grid texture, and controlled glow.
- Keep readable content on near-black surfaces. Never sacrifice contrast for decoration.

## Color system

- Base: near-black and deep plum.
- Primary accent: electric purple.
- Supporting accent: soft lavender for text emphasis.
- Status: green for synced/success, red for sync issues, gold for winners.
- Use gradients only as focused highlights, never as a full-page background.

## Typography

- Headlines: condensed, bold, uppercase display lettering.
- Supporting labels: letter-spaced uppercase microcopy.
- Body: clear sans-serif with comfortable line height.
- Avoid long all-caps paragraphs and overly decorative fonts for data.

## Layout and hierarchy

- Start each page with one clear title and one short explanation.
- Use a 12-column desktop grid and generous mobile spacing.
- Cards should share a consistent edge treatment, padding rhythm, and hover behavior.
- Keep navigation fixed, compact, and easy to scan.
- Data should be grouped into small, clearly labeled blocks rather than dense tables.

## Interaction and motion

- Motion should communicate state: cards lift on hover, sections enter softly, filters respond immediately.
- Prefer short transform/opacity animations; respect reduced-motion preferences.
- Avoid looping, distracting, or heavy effects around core information.

## Page priorities

- Home: WsB identity, creators, current events, and a clear join/community path.
- Members: simple identity cards with a visible sync state.
- Stats: searchable, sortable performance directory with useful highlights.
- Leaderboards: winners and time periods should be obvious at a glance.
- Events: event status, result, date, and CTA come before extra detail.

## Quality bar

- Every interactive item has a visible hover/focus state.
- Mobile layout is deliberate, never just a shrunken desktop layout.
- No placeholder content, broken images, clipped names, or unexplained empty areas.
- New work should reuse the established WsB colors, type hierarchy, and card language.
